Discipline

Six rules

A bright color only stays bright if it is scarce. These are the constraints that keep it working across the site, the product and the deck.

One aqua per view

A single aqua-400 element per screen — the primary action. If a second one appears, one of them is not primary and should be a ghost button.

Aqua is never body text

#00F5D4 on white is 1.4:1. As text it only exists on ink or navy. On light surfaces, aqua text means aqua-700 and nothing else.

Aqua fills carry ink labels

Always #081B2D on an aqua fill — never white, never navy-700. This pairing is fixed across both surfaces so the button reads identically everywhere.

Bright means clickable, muted means status

aqua-400 is reserved for interaction. Verified, signed and passing states use aqua-600, which is calmer and cannot be mistaken for a button.

Crimson is not a second action

It stays the mark's rule and the critical state. A red button beside an aqua button splits attention and both lose.

Ochre stays in data

Charts, percentages, editorial highlights, print. It has warmth the interface needs, but it has never been an action color and does not become one here.

Surfaces

Gradients and the edge

Three treatments, and no others. The system has one gradient with color in it — used sparingly, on hero moments and nothing else.

Signal135° · #00F5D4 → #00BBF9. Hero art, seals, key illustration. Never behind text.
Deep160° · ink → navy-700 → navy-600. Section backgrounds, deck slides, video plates.
EdgeNavy panel with a 2px aqua top rule and glow. The cheapest way to make a card feel active.
